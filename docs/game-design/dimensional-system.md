# Anchor, shifts, and passive clone

## Anchor

The awakening creates a permanent point tied to the character's soul. The anchor is the origin of returns and the source of persistence. The opening death unlocks the passive clone.

## Dimensional experience

Each discipline has two experience tracks:

- **Regular experience:** improves the current life and resets when the character returns to the anchor.
- **Dimensional experience:** persists through ordinary anchor returns and represents the character's accumulated understanding across lives.

Dimensional experience has its own level and requirement curve. It may improve persistent speed or softcaps, but does not gate story or bucket access, but those effects remain data-driven.

## Dimensional shift

A shift is crossing between realities, not simply completing an action. Its reset and persistence rules are intentionally deferred. The first implementation should model the boundary as an extension point without deciding whether dimensional experience, soulbound items, or other persistent state changes.

## Passive clone

The clone continuously generates dimensional shards while the game is closed or open. This passive accumulation is its approved role. It does not replay the life, generate ordinary loot, provide the life's discipline experience, or make route decisions.

The clone is a projection of the same awakened entity. It cannot create a second copy of persistent discipline experience or soulbound equipment.

Initial clone rules:

- the clone is unlocked by the opening death system report;
- it generates dimensional shards passively;
- it does not repeat the player's action sequence;
- custom routes and active action-running clones are not planned mechanics;
- its shard rate is a balance parameter tested by the simulator.

## Narrative transition

The character discovers anchor returns, persistent dimensional experience, and passive shard generation. Soulbound summoning gives the clone's output its purpose.
